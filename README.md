# DRZST Extractor

在 VS Code 中一键解压 `.drzst` (zstd) 与 `.zip` 文件。  
**无需安装 7-Zip 或其他外部工具**，基于 [7z-wasm](https://github.com/nicerobot/7z-wasm) 纯 WASM 实现，跨平台（Windows / Linux / macOS）开箱即用。

## 功能

### 单文件解压
- ✅ 右键 `.drzst` 或 `.zip` 文件，提供两种解压方式：
  - **解压到当前位置** – 将文件内容提取到与源文件相同的目录。
  - **解压到同名文件夹** – 创建与源文件同名的文件夹，提取到其中。

### 批量解压（默认开启，可在设置中关闭）
- ✅ 右键任意文件夹，提供四种批量解压方式：
  - **批量解压drzst到当前位置** / **批量解压zip到当前位置** – 递归查找该文件夹及其子文件夹内的所有对应格式文件，解压到各自所在目录。
  - **批量解压drzst到同名文件夹** / **批量解压zip到同名文件夹** – 同上，但为每个文件创建同名文件夹进行解压。
- ✅ 批量处理过程中会显示实时进度（当前处理第几个文件）。
- ✅ 完成后自动刷新资源管理器，并汇总成功/失败数量。

### 灵活设置
- ✅ 三种覆盖模式（设置中切换）：
  - **覆盖** – 直接覆盖已存在的文件/文件夹。
  - **重命名** – 保留旧文件，新文件或文件夹自动在末尾加 `_1`、`_2` 等序号。
  - **跳过** – 不覆盖已存在的文件/文件夹。
- ✅ 可配置是否在解压成功后**删除源文件**（默认开启，对 drzst 和 zip 均生效）。
- ✅ 可控制是否在文件夹右键菜单中**显示批量解压命令**（默认开启）。

## 安装

### 从 VS Code 扩展商店安装（推荐）
1. 打开 VS Code，按 `Ctrl+Shift+X` 进入扩展面板。
2. 搜索 `DRZST Extractor`。
3. 点击安装。

### 从 VSIX 文件安装
1. 下载 `.vsix` 文件。
2. 在扩展面板中点击 `...` → **从 VSIX 安装…**，选择文件即可。

## 使用方法

### 单个文件
1. 在文件资源管理器中找到 `.drzst` 或 `.zip` 文件。
2. 右键点击该文件。
3. 选择：
   - **解压到当前位置** – 提取后文件出现在同一目录。
   - **解压到同名文件夹** – 提取到新创建的文件夹中。

### 批量解压（默认启用）
1. 在文件资源管理器中右键点击一个文件夹。
2. 选择对应的批量解压命令（drzst 或 zip）。
3. 观察进度条，处理完毕后会弹出结果汇总。

> 💡 批量解压依然遵守你在设置中选择的覆盖模式和删除源文件策略。

## 扩展设置

你可以通过 VS Code 的设置（`Ctrl+,` 搜索 `drzst`）调整以下选项：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| `drzst-extract.deleteSource` | `true` | 解压成功后是否删除源文件。 |
| `drzst-extract.overwriteMode` | `overwrite` | 覆盖模式：`overwrite`（覆盖）/ `rename`（重命名）/ `skip`（跳过）。 |
| `drzst-extract.enableBatchExtract` | `true` | 是否在文件夹右键菜单中显示批量解压命令（drzst 与 zip 共用）。 |

## 格式支持

本扩展支持 **zstd (zstandard)** 格式（`.drzst`）和 **zip** 格式（`.zip`）。  
若你的文件是 7z、RAR、TAR 等其他格式，建议使用 [7-Zip](https://www.7-zip.org/) 等工具。

## 已知问题与限制

- 由于 7z-wasm 的内存限制，解压**超大文件（> 500 MB）** 可能失败。此类场景建议使用本地 7-Zip 并指定路径（后续版本考虑集成）。
- 批量解压会递归扫描所有子文件夹，若文件夹层级极深或文件数量巨大，可能耗时较长，请耐心等待。
- 仅支持 `.drzst` 和 `.zip` 后缀触发菜单，如需其他后缀请提交 Issue。
